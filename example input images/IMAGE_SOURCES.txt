## Example Image Sources

Some example input images used in this repository and in the associated
experiments are drawn from the following publicly available research datasets:

- **MS COCO** — Lin et al., *Microsoft COCO: Common Objects in Context*,
  ECCV 2014.  
  https://cocodataset.org/

- **Places365** — Zhou et al., *Places: A 10 Million Image Database for
  Scene Recognition*, IEEE Transactions on Pattern Analysis and Machine
  Intelligence, 2018.  
  http://places2.csail.mit.edu/

These third-party images are used for research and evaluation purposes.

original source code in this repository. Copyright and usage rights for
third-party images remain with their respective owners and are subject to
